# User Personas & Access Roles

Befroosh enforces 6 strict RBAC roles:

1. **`guest` (Unauthenticated Visitor)**: Browses public storefronts, uses local storage cart and favorites.
2. **`customer`**: Authenticated shopper with 30-day persistent session, saved addresses, order tracking stepper, and support ticket center.
3. **`shop_owner` (Business Owner)**: Tenant administrator. Manages branches, staff assignments, catalog, bank cards, accounting ledger, and subscription plans.
4. **`shop_manager`**: Senior tenant staff. Manages orders, verifies payment receipts, updates inventory, and replies to support inquiries.
5. **`branch_manager`**: Local outlet manager. Scoped specifically to branch order fulfillment and branch-specific stock taking.
6. **`superadmin`**: Platform owner. Controls tenant subscriptions, global retention policies, system abuse reports, and user impersonation.
