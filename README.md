# Befroosh (بفروش)

A simple, fast, and feature-rich multi-tenant CMS tailored for small businesses and social media-based shops (فروشگاه‌های آنلاین و شبکه‌های اجتماعی).

---

## 🌟 ویژگی‌های کلیدی (Key Features)

- **چند فروشگاهی (Multi-Tenant Architecture)**: هر فروشگاه دارای لندینگ اختصاصی، مدیر، محصولات و گزارش‌های تفکیک‌شده است.
- **بدون درگاه آنلاین (Offline Payment / Card-to-Card)**: پشتیبانی از کارت‌به‌کارت با قابلیت بارگذاری رسید واریز و تأیید/رد توسط مدیر فروشگاه.
- **توزیع نقش‌ها و دسترسی‌ها (Role-Based Access Control)**:
  - **مدیر کل سامانه (Super Admin)**: نظارت بر کل سیستم، فروشگاه‌ها، کاربران و گزارش‌ها.
  - **مالک فروشگاه (Shop Owner)**: مدیریت کامل فروشگاه، محصولات، مالی، انبار و مدیران.
  - **مدیر فروشگاه (Shop Manager)**: رسیدگی به سفارش‌ها، پاسخ تیکت‌ها و به‌روزرسانی موجودی/قیمت.
  - **مشتری (Customer)**: نشست طولانی‌مدت (۳۰ روزه)، سابقه خرید و پیگیری مرسوله‌ها در سراسر فروشگاه‌ها.
- **مدیریت پیشرفته انبار و حسابداری (Inventory & Accounting)**:
  - رزرو خودکار موجودی کالا تا زمان بررسی سفارش (پیش‌فرض ۴ روز).
  - سند حسابداری خودکار، گزارش سود و زیان و تراز مالی هر فروشگاه.
  - محدودیت تعداد خرید در هر سفارش و در هر ماه برای هر کاربر.
- **رهگیری سفارش و بارکدخوان (Order Tracking & Barcode)**:
  - پیگیری عمومی و محرمانه وضعیت سفارش با تایم‌لاین مراحل (ثبت، پرداخت، تأیید، ارسال، تحویل).
  - پشتیبانی از دستگاه‌های بارکدخوان و چاپ بارکد/کیوآر کد اختصاصی برای سبد خرید مستقیم.
- **کاملاً آفلاین و بومی (Offline-First & Self-Contained)**:
  - قلم وزیرمتن (Vazirmatn)، Alpine.js، و Tailwind CSS کاملاً محلی در پوشه `assets/` (بدون وابستگی به CDN خارجی).
- **معماری ماژولار و بهینه (Modular Architecture)**:
  - تفکیک مسیرها به فایل‌های مجزا (`routes_*.php`).
  - پایگاه داده سبک و یکپارچه SQLite با قابلیت جابجایی آسان.

## 🚀 راه‌اندازی سریع (Quick Start)

1. مخزن را کلون کنید:
   ```bash
   git clone https://github.com/sinavali/Befroosh.git
   ```
2. پروژه را در وب‌سرور محلی (مانند Laragon یا Apache/Nginx با PHP 8.1+) اجرا کنید.
3. جهت راه‌اندازی پایگاه داده و داده‌های نمونه اولیه، به آدرس زیر در مرورگر بروید:
   ```
   http://localhost/setup.php
   ```
4. اطلاعات ورود پیش‌فرض:
   - **مدیر کل**: `admin` / رمز عبور: `admin123`
   - **مالک فروشگاه**: `owner_tech` / رمز عبور: `owner123`
   - **مدیر فروشگاه**: `manager_tech` / رمز عبور: `manager123`
   - **مشتری**: `customer1` / رمز عبور: `customer123`
